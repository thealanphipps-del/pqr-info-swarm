# Sovereignty Roadmap: DEX, Governance, and Registrar

## 1. DEX.pqr.info (Automated Market Maker)
The DEX provides liquidity for PQR, SURFGO, and GO tokens. It utilizes the swarm's own agents as liquidity providers to minimize slippage for large transfers.

## 2. GOVERNANCE.pqr.info (On-Chain DAO)
A transparent, ledger-linked voting portal. Citizens stake PQR to participate in mesh mutations, IP registration policies, and cross-chain budget allocations.

## 3. REGISTRAR.pqr.info (Official TLD & IP Registry)
The public interface for registering `.mh` domains, patents, and copyright hashes. Every entry is burned as an immutable record on the PQR Chain, and entries are automatically synched with Cloudflare/global resolvers.

## Compliance Audit (By-The-Book)
To operate above board, we maintain the following:
*   **KYC/AML Compliance**: The swarm agents perform non-custodial risk assessment using the Agent Identity Protocol (verified passporting).
*   **Auditable Ledger**: Every swap, vote, and registration generates an immutable entry in the Sovereign ledger, accessible for forensic audit.
*   **Tax Compliance**: Built-in automated reporting triggers whenever a 'Citizen' reaches the tax jurisdiction thresholds set by their designated 'Agent Guardian.'
