# METAGO(1) | Sovereign Node Manual

## NAME
metago - Meta-Programming and Hyperdevelopment Framework

## SYNOPSIS
**metago** [COMMAND]

## DESCRIPTION
**metago** is the "Meta-Programming" engine of the ecosystem. It is responsible for autonomous code generation, self-optimization, and hot-reloading of the Sovereign Node Go logic.

## CORE LOGIC
- **Autonomous Cycles**: Generates Go code based on forensic logs and trading signals.
- **Hot-Reload**: Injects updated logic into the running system via the Secure Injection Layer.
- **Hyper-Tasks**: Tracks high-velocity self-improvement cycles in `meta/hyper_task.md`.

## COMMANDS
- **generate**: Trigger a new meta-programming cycle.
- **sync**: Push generated logic across the mesh bridge.

## FILES
- **pkg/meta/metago.go**: Core generation logic.
- **scripts/meta/generator.sh**: Automation script for compilation and injection.
