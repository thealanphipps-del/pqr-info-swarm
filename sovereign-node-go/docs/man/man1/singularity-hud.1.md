# SINGULARITY-HUD(1) | Sovereign Node Manual

## NAME
singularity-hud - Real-Time Visual Dashboard and Command Interface

## DESCRIPTION
**Singularity HUD** is the visual front-end for the Sovereign Node. It provides real-time monitoring of trading metrics, mesh status, and forensic logs.

## INTERFACE
- **Dashboard**: Displays RSI signals, asset locks, and mesh connectivity.
- **Command Link**: Allows for manual overrides and "Meta-Hook" initialization.

## NETWORK
- **Port**: 8081 (HTTP)
- **Protocol**: Web-based interface accessible via the bridge IP.

## CONTEXT
The HUD is a critical component for human-in-the-loop oversight during "Hyperdevelopment" cycles.
