# RTGO API Methods Documentation

## Overview
The Sovereign Mesh exposes a lightweight HTTP bridge (`http://192.168.12.201:8081`) that forwards commands to the underlying Termux environment.  The primary programmable interface is the **RPC bridge** listening on **port 1111**.  All RPC calls are defined in the protobuf files shipped with the project.

---
### Discovered Protobuf Services
| Proto File | Service | RPC Method | Request Message | Response Message |
|------------|---------|-----------|----------------|-----------------|
| `gemini_handshake.proto` | `GeminiService` | `Handshake` | `HandshakeRequest` (fields: `sender_id`, `message`) | `HandshakeResponse` (fields: `status`, `payload`) |
| `gshell.proto` | `ShellService` | `Execute` | `ShellExecuteRequest` (fields: `uid`, `command`, `persist`) | `ShellExecuteResponse` (fields: `output`, `exit_code`) |
| `gshell.proto` | `ShellService` | `Version` | `VersionRequest` (empty) | `VersionResponse` (fields: `version`, `git_sha`) |
| `gshell.proto` | `ShellService` | `Status` | `StatusRequest` (empty) | `StatusResponse` (fields: `status`, `uptime`) |
| `gshell.proto` | `ShellService` | `List` | `ListRequest` (empty) | `ListResponse` (repeated `method_name`) |

---
### RPC Bridge HTTP Endpoints
| HTTP Endpoint | Description |
|---------------|-------------|
| `POST /api/bridge?cmd=<command>` | Executes an arbitrary shell command on the Termux side and returns raw stdout/stderr. |
| `GET /api/status` | Returns a short health/status string (used by the UI dashboard). |
| `GET /api/bridge` | Returns a static HTML UI for manual command entry. |

### Example Calls (via the bridge)
```bash
# List available RPC methods (internal helper)
curl -s http://127.0.0.1:1111/rpc/list

# Perform a Handshake
curl -X POST http://127.0.0.1:1111/rpc/execute \
    -H "Content-Type: application/json" \
    -H "X-Callsign: AELLK" \
    -d '{"uid":10463,"command":"GeminiService/Handshake","persist":true,"payload":"{\"sender_id\":\"UID_10463\",\"message\":\"RECONSTRUCT_MESH\"}"}'

# Execute a shell command via the RPC bridge
curl -X POST http://127.0.0.1:1111/rpc/execute \
    -H "Content-Type: application/json" \
    -H "X-Callsign: AELLK" \
    -d '{"uid":10463,"command":"ShellService/Execute","persist":true,"payload":"{\"command\":\"whoami\"}"}'
```
